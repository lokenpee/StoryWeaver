# 推送

## 触发条件

用户说以下任意模式时激活：
- "推送 + 版本号"（如 `推送 3.21.0`、`推送 v3.21.0`）
- "push 版本号"（如 `push 3.21.0`）
- "推送版本"
- "push version"
- "commit and push"

## 执行流程

### 1. 解析版本号

从用户输入中提取版本号（如 `3.21.0` 或 `v3.21.0`），统一去掉 `v` 前缀。

如果用户只说"推送"没带版本号，用当前 `manifest.json` 里的版本号。

### 2. 更新版本号（两处）

**manifest.json** — 插件元数据：
```
"version": "3.23.0"
```

**settingsPanel.js** — UI 显示的版本号（第 90 行）：
```
const PLUGIN_VERSION = 'v3.23.0';
```

两处必须同步更新。

### 3. 提交

```bash
git add manifest.json
git commit -m "v{版本号}: 版本号更新"
```

如果工作区有 `txtToWorldbook/` 下的改动需要一起提交：
```bash
git add txtToWorldbook/
git commit -m "v{版本号}: <改动摘要>"
```

### 4. 拉取并变基

```bash
# stash 噪声文件（如 .codegraph/daemon.pid）
git stash push -- .codegraph/daemon.pid 2>/dev/null || true
git pull origin master --rebase
git stash pop 2>/dev/null || true
```

变基冲突时自动解决 — 我们的改动优先级高于远程。

### 5. 推送

```bash
git push origin master
```

**注意**: git push 会被 git-guardrails PreToolUse hook 拦截。此时提示用户手动执行：
> push 被安全钩子拦截，请手动执行：`git push origin master`
